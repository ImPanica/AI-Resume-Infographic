# 🐉 AI Resume Infographic Generator

Этот prompt превращает обычное резюме в **одностраничную premium CV-инфографику** с профессиональным профилем кандидата, визуальной аналитикой, китайским зодиаком, западным знаком зодиака, нумерологией и случайной китайской мудростью.

Потому что обычного `Experience / Skills / Education` иногда недостаточно.  
Иногда HR должен узнать, что ты **Земляная Змея с числом жизненного пути 7 и 94.8% Team Compatibility**. 🐍

---

## ✨ Что делает prompt

Промпт анализирует данные кандидата и автоматически формирует:

- 👤 имя и профессиональное позиционирование;
- 💼 должность и специализацию;
- 🧠 ключевые навыки;
- 🛠️ технологии и инструменты;
- 🚀 реализованные проекты;
- 📈 достижения и measurable impact;
- 🎯 блок **"Why I'm a good fit"**;
- 🤝 условный **Team Compatibility Score**;
- 🎓 образование;
- 🌍 языки;
- ♈ западный знак зодиака;
- 🐉 китайский зодиак и стихию;
- 🔢 число жизненного пути;
- ☯️ китайскую мудрость;
- 🖼️ профессиональную фотографию;
- 🏯 китайскую visual identity.

Всё это собирается в **одну вертикальную страницу**.

---

## 🎨 Как это выглядит

Идея — объединить:

**Professional Tech CV**  
+  
**Executive Profile**  
+  
**Infographic**  
+

+

# 🚀 Как использовать

## 1. Открой AI, который умеет генерировать изображения

Например, используй модель с возможностью image generation.

## 2. Добавь Master Prompt

Скопируй содержимое:

`AI_Resume_Infographic_Master_Prompt.md`

или вставь его целиком в чат.

## 3. Передай данные кандидата

Минимально нужны:

```text
Имя:
Иван Иванов

Дата рождения:
15.07.1992

Должность:
Senior QA Automation Engineer

Опыт:
8 лет

Навыки:
C#, Selenium, Playwright, NUnit, API Testing...

Проекты:
...

Достижения:
...

Образование:
...

Языки:
...

```

И, желательно, добавь:

**📸 фотографию кандидата**

---

## 4. Попроси создать CV

Например:

```text
Используй Master Prompt.

Данные кандидата:

[ВСТАВЬ РЕЗЮМЕ]

Дата рождения:
15.07.1992

Создай одностраничную premium CV infographic.

Используй фотографию, которую я прикрепил.

Не выдумывай профессиональные факты.
Астрологические элементы используй только как декоративную часть.
```

После этого модель должна самостоятельно:

1. проанализировать кандидата;
2. определить его профессиональный профиль;
3. определить западный знак;
4. определить китайский зодиак;
5. определить стихию;
6. рассчитать число жизненного пути;
7. выбрать подходящую китайскую мудрость;
8. сформировать Team Fit Score;
9. подобрать визуальную композицию;
10. создать финальную инфографику.

# 🧩 Что можно менять

Master Prompt специально сделан так, чтобы его можно было адаптировать.

### Можно изменить визуальный стиль

Например:

```text
Сделай визуальный стиль более минималистичным и европейским.
Убери большую часть китайских декоративных элементов.
Оставь только небольшой символ китайского зодиака.
```

или:

```text
Сделай дизайн более futuristic / cyberpunk.
Сохрани структуру CV.
Китайскую эстетику замени на японский минимализм.
```

---

### Можно убрать астрологию

```text
Убери западную астрологию и нумерологию.
Оставь только китайский зодиак как небольшой декоративный элемент.
```

---

### Можно сделать корпоративную версию

```text
Сделай дизайн более строгим и корпоративным.
Минимизируй декоративные элементы.
Сохрани infographic structure.
Сделай акцент на achievements, skills и business impact.
```

# ⚠️ Важное ограничение

Этот prompt специально содержит защиту от выдумывания информации.

Модель **не должна придумывать**:

- опыт работы;
- компании;
- технологии;
- проекты;
- достижения;
- цифры;
- образование;
- сертификаты;
- языки;
- клиентов.

Если информации нет — лучше оставить блок компактным.

А вот следующие элементы являются намеренно декоративными:

- ♈ астрология;
- 🐉 китайский зодиак;
- 🔢 нумерология;
- 🤝 Team Compatibility Score;
- ☯️ китайская мудрость.

То есть **не стоит принимать решение о найме человека на основании того, что он родился в год Змеи**.

Хотя выглядит это, конечно, убедительно. 🐍

# 🎯 Для чего это вообще?

Главная идея проекта — эксперимент с тем, как **AI может превращать обычные структурированные данные резюме в персонализированный visual career profile**.

Вместо:

```text
8 years experience
C#
Selenium
API
SQL
CI/CD
...
```

получаем:

> **Кто этот человек → в чём его сила → что он сделал → чем полезен команде**

А затем добавляем немного:

> **🐍 Земляная Змея + ☯️ китайская мудрость + 96.4% Team Fit**

Потому что серьёзный hiring process иногда тоже заслуживает немного юмора.
